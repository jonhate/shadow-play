# 台词表（配音用）

> 本文件由 `node tools/export-lines.mjs` 生成，改台词请改 `app/show.js` 后重新导出。

## 怎么用

1. 按下面的「文件名」，给每一句生成一个 mp3（任意 TTS 都行，建议 zh-CN 男声/女声分角色）；
2. 放到对应路径（`audio/lines/<场景id>/01.mp3` …），文件名必须一模一样；
3. 刷新页面即可。缺哪个就静音跳过，不会报错。

批量生成示例（edge-tts，免费）：

```bash
pip install edge-tts
edge-tts --voice zh-CN-YunxiNeural  --text "待月西厢下，迎风户半开。" --write-media audio/lines/xiang/01.mp3
edge-tts --voice zh-CN-XiaoxiaoNeural --text "先生万福。"           --write-media audio/lines/xiang/03.mp3
```

播台词时背景音乐会自动压低（ducking），念完再恢复。
