# 手指控制皮影：调研与方案

> 调研目的：网上有些项目用「一根手指控制一个位置」的方式操作皮影/木偶，
> 我们想判断这套交互能不能搬到本展项（单目摄像头 + MediaPipe）。

---

## 一、传统皮影到底怎么被"手指"控制

这不是新发明的交互，**传统皮影本来就是用手指控的**。三根竹签的分工（据 Stanford CCRMA 关于皮影操作的整理）：

| 竹签 | 位置 | 握法 |
| --- | --- | --- |
| **平衡杆**（1 根） | 挂在颈部/胸前 | 拇指在一侧，**其余四指在另一侧**，握稳 |
| **动作杆**（2 根） | 分挂左右两臂 | 一根握在**拇指与食指之间**；另一根握在**中指、无名指、小指之间**（无名指在上、中指与小指在下） |

两种基本技法：

- **搓签（rubbing / rolling）**：在拇指与食指之间搓动竹签 → 改变关节朝向 → 产生各种身段；
- **抬落（raising / lowering）**：抬落平衡杆 → 皮影在幕上上下移动。

台湾皮影常用**两根签**，所以一只手可以同时控多个皮影。

**结论**：真实操作里，「哪根手指夹哪根签」是有明确分工的——这正是网上那些"一根手指控一个位置"项目的原型。

参考：
- [Puppet Manipulation（Stanford CCRMA，Shadow 项目）](https://ccrma.stanford.edu/~bt5/shadow/text-puppet_manipulation.html)
- [ADVANCED SHADOW PUPPETS（Hobey Ford，传统操作手册）](http://www.hobeyford.com/files/ADVANCED%20SHADOW%20PUPPETS.pdf)

### 共性结论

1. **主流是「捏合（pinch）= 抓住一根签」**：拇指与其他手指的捏合距离，天然对应"夹住竹签"这个动作；
2. **一根签对应一个自由度**：签的位置 → 手/臂末端位置；搓动（旋转）→ 关节朝向；
3. **单目摄像头的精度瓶颈在无名指和小指**：MediaPipe 对这两指的抖动明显大于拇指/食指，所以"五指各控一签"的方案在普通摄像头上容易抖；
4. **深度相机（Leap Motion / RealSense）能明显改善**，但展馆要多一套硬件与标定成本。

## 三、给本展项的建议方案

### 方案 A（推荐，先做这个）：捏合即执签

| 输入 | 映射 | 说明 |
| --- | --- | --- |
| 拇指 + 食指捏合距离 | 左臂那根"动作杆"：捏得越紧越"握住" | 距离 < 阈值 = 执签，手臂定住；> 阈值 = 放开，手臂跟手掌走 |
| 中指 + 无名指 + 小指合拢 | 右臂那根"动作杆" | 同上 |
| 掌心位置 | 平衡杆 → 皮影整体位置（含水平走位） | 已经在用 |
| 拇指与食指的**搓动角** | 关节朝向（手腕旋转） | 对应传统"搓签"，这是最出彩的一点 |

优点：只依赖 MediaPipe 已有 21 点里的 4 个指尖（4/8/12/16），精度够；和现有"握拳=定住"兼容，可作为进阶模式。
风险：需要现场调阈值；两只手同时捏合时容易误判。

### 方案 B：五指分工（更接近真实，但更抖）

拇指→平衡杆（整体位置）、食指→左臂、中指→右臂、无名指+小指→走位。
**不建议作为默认**：无名指/小指在 960×540 的单目画面里抖动大，观感会"抽"。

### 方案 C：不做手指，做"签位"

把"手"抽象成两个可拖动的点（我们现在的做法），只在**教学关**里用动画演示真实握签姿势，讲清"为什么是这样"。
成本最低、最稳，适合展馆长时间无人值守。

### 落地顺序建议

1. 保留现有「张手跟手 / 握拳定住」作为**基础模式**（已验证稳定）；
2. 增加 **`?finger=1` 进阶模式**：启用捏合执签 + 搓动转向，作为"非遗深度体验"；
3. 教学关里加一段"真实握签"的图解，讲清三根签的分工（这部分现在缺，是最能体现"传承"的内容）；
4. 现场用真机标定阈值，把数字写进 `app/gesture.js` 顶部常量，便于调。

> 现状：本文件是调研结论与方案，代码里**尚未**实现方案 A/B。
> 需要实现时按上面第 2 条加开关，不影响现有已验证的交互。
