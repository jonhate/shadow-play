## 3、作品简介

《掌中戲 · 手势皮影》是一个可现场上手操作的数字皮影戏展项。观众站到屏幕前，举起双手，幕布上的皮影便随人而动：张开手掌，皮影的手跟着你走；握拳，那只手就"执签"定住；两手一合是作揖，双手举高是亮相；手掌左右平移，皮影便迈步走位。系统用普通摄像头识别手部 21 个关键点，驱动皮影的分件关节（肩、肘、腕逐级求解），还原"分件 + 关节 + 竹签"的真实结构，而不是播放预制动画。

作品包含六出戏：月上柳梢、沙场点兵、仙翁跨鹤，以及改编自《西厢记》《霸王别姬》《八仙过海》的三出，台词会随着观众的动作推进——做出"作揖"，戏才往下走一句，观众从看客变成操偶人。另设五步教学关，每一步必须真的做出来才通过；六出演完，还会自动演一段约 24 秒的谢幕。

创新之处有三点。一是把真实技法转成交互：除基础的"张手跟手、握拳执签"，还做了"捏合执签 + 搓动转腕"的进阶模式，拇指与食指捏住即夹住竹签，两指连线转动即传统"搓签"转腕，依据的是传统三根竹签的真实握法。二是叙事与动作绑定：台词不由时间轴自动播完，而要观众用动作推进，动作即台词。三是舞台语言的完整还原：灯箱背光剪影、剪纸红金配色、竖排题名与朱印落款，并提供剪影 / 镂空 / 套色三档皮，以及双人同台（两位观众各控一个皮影）。

应用价值：适用于博物馆、非遗馆、学校美育课堂与文旅展陈。全部资产与依赖本地化，断网可运行，一台普通电脑加一个摄像头即可部署，双击即启、无人值守；换一套皮影资产就能出新角色，内容可持续生长。

## 4、创意来源

皮影戏是我国入选联合国教科文组织人类非物质文化遗产代表作名录的传统戏剧。它的魅力不在"看"，而在"耍"——艺人一手执三根竹签，一根撑头颈身，两根挑双手，靠拇指与食指间"搓签"改变关节朝向，靠抬落平衡杆让皮影上下进退。但也正因如此，它难学、难传：手上功夫要练多年，观众在展厅里通常只能隔着玻璃看，很少有机会亲手试一试。

我最初的疑问是：为什么现有的手势互动展项，大多只是"挥手翻页、隔空点击"？这些交互与皮影的操作逻辑毫无关系，观众玩完记不住皮影是什么。于是我决定不做"用手势控制动画"，而是把**三根竹签的操作逻辑直接映射到手上**——尤其是"执签"（握住才带得动）与"搓签"（转动即转腕）这两个真实技法，让第一次上手的人也能体会到"我是在耍皮影"，而不是"我在玩游戏"。

核心创意由此展开：一是"动作即台词"，把作揖、亮相、甩袖设计成推动剧情的关键动作，让观众为了看下一句而主动学动作；二是"教与演一体"，用必须真做出来才能通过的教学关，把非遗的"手把手"过程做成可复制的展陈环节；三是"以简驭繁"，只用手掌与指尖这几个稳定信号，就能驱动有十来个关节的皮影，保证普通摄像头、普通电脑也能稳定运行，便于在基层场馆推广。

## 5、运行环境

一、软件环境
操作系统：Windows 10 / 11 64 位（macOS、Linux 同理，只需具备 Node.js 与 Chromium 内核浏览器）。
运行时：Node.js 18 及以上（本作品实测 v24.18），仅用于启动本地静态服务器。
浏览器：Microsoft Edge 或 Google Chrome（Chromium 100 及以上），需支持 WebGL2、WebAudio 与 getUserMedia 摄像头接口。
依赖与素材：three.js、fflate、MediaPipe Tasks-Vision（含手势模型 8.2MB 与 wasm）、15 个 .woop 皮影资产、戏剧原声与音效，全部本地化存放，无需 npm install，无需联网即可运行。

二、硬件环境
摄像头：720p 及以上 USB 摄像头，建议 1080p / 30fps（程序按 960×540 采集）。
主机：近五年普通办公机型即可，集成显卡可运行，手势推理约 20–40 毫秒/帧；建议 i5 八代以上、8GB 内存。
显示：1920×1080 及以上，展馆建议 4K 电视或投影；另有 4:3 自适应布局。
音响：普通有源音箱，用于播放戏剧原声与锣鼓音效。
可选：触摸屏（用于调出使用引导与教学关）。
不需要深度相机、穿戴设备或专用传感器，单目摄像头即可。

三、启动与部署
双击项目根目录的「启动掌中戏.cmd」（或桌面快捷方式），程序会自动启动本地服务器并打开浏览器；也可手动执行 node tools/serve.mjs 后访问 http://127.0.0.1:5173/。
在线演示地址：https://jonhate.github.io/shadow-play/（HTTPS，浏览器打开后点击页面并允许摄像头即可试玩；首次加载需下载手势模型与皮影资产，约 10–20 秒）。
必须通过 http://127.0.0.1:5173/ 或 https 访问，直接双击 index.html 无法调用摄像头。
首次进入需点击页面一次以申请摄像头权限；无摄像头时可开启右下角「鼠标」开关以鼠标演示。
展馆模式：在地址后加 ?kiosk=1（全屏、隐藏鼠标、屏蔽右键、出错自愈）；双人同台加 ?duo=1。
自带三个自检工具：camtest.html 检查摄像头权限与设备、audiotest.html 逐句试听台词与背景音乐、?debug=1 打开实时诊断面板（帧率、识别手数、推理耗时）。
